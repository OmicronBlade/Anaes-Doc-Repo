# Regional consent forms — v1 (archived 26 Oct 2026)

The first version of the four NSH regional anaesthesia consent forms, kept so it can be restored.
It has a detailed risk table on the form itself (one row per risk, with tick box and frequency),
Catheter as a technique option, and the WCG logo in the letterhead.

This folder is self-contained (its own copy of the content, layout and styles), so it keeps working
even when the live forms change. Open any `regional-consent-*.html` here in the browser; blank print
versions are in `pdf/`. Drafts are saved separately from the live forms.

The live forms are `forms/regional-consent-*.html`.
